# 部署手册｜阶段3：Jenkins CI/CD 流水线

> 项目：K8s 云原生平台
> 内容：Jenkins on K8s + Pipeline as Code（构建→推送Harbor→Helm部署→健康检查→回滚）
> 更新日期：2026-08-26

---

## 一、架构

```
开发者 git push → Poll SCM(每2分钟) → Jenkins(集群内, NodePort 32000)
  → 动态 Agent Pod(kubernetes 插件, jenkins-agent 镜像)
     1. Checkout 业务代码(GitHub 公开仓库)
     2. docker build 两个镜像(挂载宿主 docker.sock)
     3. docker push → Harbor
     4. helm upgrade links-chart(agent 内置 helm+kubectl, kubeconfig 挂载)
     5. 健康检查 http://links-nginx.links-ns.svc:80/health
     6. 失败自动 helm rollback
```

## 二、Jenkins 部署

```bash
helm repo add jenkins https://charts.jenkins.io
helm install jenkins jenkins/jenkins -f jenkins/values.yaml -n jenkins --create-namespace
```

访问 `http://192.168.80.133:32000`（admin / 密码在 secret：`kubectl -n jenkins get secret jenkins -o jsonpath='{.data.jenkins-admin-password}' | base64 -d`）

### 关键配置（jenkins/values.yaml）

| 配置 | 值 | 说明 |
|---|---|---|
| controller.image | Harbor 私有镜像 | **docker.io 在国内网络拉不动**（auth.docker.io 被代理重置），改为从 Harbor 拉 |
| controller.imagePullSecretName | harbor-registry-secret | 私有仓库拉取凭据 |
| controller.pluginUpdateCenter | 清华镜像 | 插件下载加速 |
| agent.image | jenkins-agent:1.1 | 自建镜像：inbound-agent + helm + kubectl + docker CLI(27) |
| agent.runAsUser/runAsGroup | 0 | root 访问宿主 docker.sock（学习环境；生产应专用构建账号） |
| agent.volumes | docker.sock + kubeconfig secret | 构建镜像 + 操作集群 |
| agent.imagePullSecretName | harbor-registry-secret | agent 拉私有镜像 |

### 动态 Agent 镜像（jenkins/agent/Dockerfile）

inbound-agent 基础 + helm（get.helm.sh）+ kubectl（阿里云 apt）+ docker CLI（从 docker:27-cli COPY）

## 三、Pipeline（Jenkinsfile，存业务仓库 k8s-blog-web）

```groovy
pipeline {
    agent { label 'jenkins-jenkins-agent' }
    environment { HARBOR='...'; IMAGE_TAG="v${BUILD_NUMBER}" }
    stages {
        Checkout SCM          // GitHub 公开仓库自动拉取
        构建镜像              // docker build app/ + nginx
        推送镜像到 Harbor     // 凭据 id: harbor（JCasC 配置）
        Helm 升级部署         // clone manifest 仓库 + helm upgrade --set 镜像tag
        部署后健康检查         // curl 集群内 Service /health
    }
    post { failure { helm rollback } }
}
```

触发方式：**Poll SCM 每 2 分钟**（内网环境 GitHub webhook 无法到达 Jenkins；有公网后可以换 webhook）

## 五、踩坑记录（阶段3）

| # | 现象 | 根因 | 解决 |
|---|---|---|---|
| 1 | Jenkins 主镜像 ImagePullBackOff | docker.io auth 被代理重置 | docker pull → 推 Harbor → chart 换镜像源 |
| 2 | `no basic auth credentials` | StatefulSet 缺 imagePullSecrets | `controller.imagePullSecretName` |
| 3 | NodePort 丢失变 ClusterIP | values.yaml 重复 `controller:` 键，后者覆盖前者 | 合并为一个 controller 块（YAML 陷阱） |
| 4 | 插件/镜像拉取慢 | 官方源国内慢 | 清华插件源 + Harbor 私有镜像 |
| 5 | Jenkinsfile 报 `expecting '!'` | Groovy 不支持 `#` 注释 | 改 `//` |
| 6 | `permission denied` docker.sock | agent 非 root，不在 docker 组 | agent runAsUser 0 |
| 7 | `client version 1.43 is too old` | agent docker CLI 24 < 宿主 daemon API | docker CLI 升级 27（镜像 1.1） |
| 8 | helm `release: not found` | 回滚没指定命名空间（release 在 default） | helm 命令统一 `-n default` |
| 9 | config.xml 回传 500 | 中文特殊字符导致 XML 非法 | 用纯 ASCII 重建配置 |
