## 一、Ansible（配置管理）

### 目录结构（ansible/）

```
ansible/
├── inventory.ini      # 主机清单（单节点 + 多节点扩展注释）
├── ansible.cfg        # 配置（host_key_checking off）
├── init-cluster.yml   # 集群初始化（阶段0 代码化，幂等）
└── check-cluster.yml  # 集群巡检（生成报告）
```

### init-cluster.yml（幂等可重复执行）

把阶段0 的手动步骤代码化：关 swap / 内核模块 / sysctl / containerd（cgroup v2 + 阿里云沙箱镜像）/ kubeadm/kubelet/kubectl 安装 + 版本锁定。

```bash
ansible-playbook -i inventory.ini init-cluster.yml
# 验证结果：14 ok / 0 failed（重复执行幂等，只有需要变更的才 changed）
```

### check-cluster.yml（巡检报告）

收集：节点状态 / 资源使用(kubectl top) / 命名空间 / 异常 Pod / 系统资源 → 输出 `/tmp/巡检报告-<日期>.txt`

```bash
ansible-playbook -i inventory.ini check-cluster.yml
# 可配合 cron 定期执行：0 8 * * * cd ~/k8s/ansible && ansible-playbook -i inventory.ini check-cluster.yml
```

### 踩坑

| 问题 | 解决 |
|---|---|
| Missing sudo password | 配置 zqq 免密：`echo "zqq ALL=(ALL) NOPASSWD:ALL" \| sudo tee /etc/sudoers.d/zqq` |
| kubectl 连不上集群 | become root 后 HOME 变化，任务显式 `environment: KUBECONFIG: /home/zqq/.kube/config` |
| GPG key 下载卡住 | 任务加 `--connect-timeout 10 --max-time 30` + 已存在跳过 |
| 磁盘显示 38413GB | 单位换算：字节→GB 需除三次 1024/1024/1024 |

## 二、Terraform（IaC 学习模板）

```
terraform/
├── main.tf        # 阿里云 ECS(1主2从) + 安全组(6443 + 内网互通)
├── variables.tf   # 地域/规格/镜像/网段
├── outputs.tf     # 实例信息输出
└── README.md      # 使用说明（学习用，不执行 apply）
```

**核心价值**：演示"用代码定义基础设施"的 IaC 思想——3 台虚拟机对应 3 台 ECS，安全组对应 VMware NAT 网段。有云账号后可 `terraform init/plan/apply`。

## 三、MySQL 定时备份（K8s CronJob）

`helm-charts/links-chart/templates/backup-cronjob.yaml`

- **schedule**: `0 3 * * *`（每天凌晨 3 点）
- 流程：`mysqldump` links_db → `/backup/links_db_<时间戳>.sql`（LocalPV 2Gi）→ 保留最近 7 份
- 密码从 Secret 读取（`MYSQL_ROOT_PASSWORD`）

```bash
# 手动触发验证
kubectl -n links-ns create job --from=cronjob/links-mysql-backup backup-test
kubectl -n links-ns logs job/backup-test | tail
# 查看备份
kubectl -n links-ns exec links-mysql-0 -- ls -lh /backup
```

**验证记录**：手动触发成功，生成 `links_db_20260826_0210.sql`（2.5K）

## 四、与 CI/CD 的关系

- 备份 CronJob 已并入 links-chart，随 helm 统一管理
- Ansible 巡检可挂 cron 定期执行，异常输出作为告警/复盘素材
- Terraform 模板作为简历展示"IaC 思想"，不实际执行
